# Matrix Eyes Cam

A virtual webcam for macOS. Pick a background and what your silhouette becomes once, and every Google Meet / Zoom / FaceTime call starts with that look: you as liquid chrome in space next to a black hole, a hologram walking an endless twisting corridor, a quartz statue on Escher's stairs, or just you with a tidy, blurred room.

![Looks](docs/looks.jpg)

<sub>Rendered offline from the NASA portrait of astronaut Eileen Collins (public domain). In a call it's you, live.</sub>

## What's in it

**Backgrounds**

| Your room | Animated scenes | Impossible spaces |
| --- | --- | --- |
| Room as it is | Space (+ ray-traced black hole) | Infinite corridor: an arched hall that slowly twists, so the checkered floor climbs the walls |
| Blurred room (no halo around you) | Matrix rain | Escher stairs: staircases in every direction, slowly turning |
| Tidy room (soft, desaturated studio look) | Aurora, Synthwave | Fractal cathedral: an endless flight down a Menger-sponge tunnel |

**You**

| Mode | Options |
| --- | --- |
| As you are | colour grade: natural, noir, warm film, cyberpunk |
| Effect | edge glow, hologram, neon outline, pixelate, ghost trails; colour and strength |
| Material | Silver Surfer chrome, quartz statue, verdigris copper, bronze, doodle, 3D print (from Matrix Eyes) |
| Fill | galaxy, fire, ocean, lava, or **your own image or looping video** |
| Matrix code | you, made of digital rain, shaped in 3D |

Looks are saved as presets (13 built in), switchable from the window or the menu bar. Your cut-out comes from Apple's person segmentation, materials use the Depth Anything V2 depth model on the Neural Engine, and everything renders with Metal at 1280×720, 30 fps (each frame takes 1–5 ms of GPU time on an M4).

People in the call see you **unmirrored**, so text on your shirt or a whiteboard reads correctly; the studio preview is mirrored like a mirror.

macOS only loads a camera extension that is signed by an Apple developer team with the system-extension entitlement. Until that's set up, the **Output** window (Studio › Virtual camera › Open clean output window) shows exactly the call picture and can be captured by OBS's virtual camera as a stopgap.

## Run the studio app

```bash
./build.sh
open "Matrix Eyes Cam.app"
```

Needs macOS 14+, Apple silicon and Xcode. The depth model is shared with Matrix Eyes (`../Models`, fetched by `../scripts/fetch-model.sh` if missing).

## Build with the virtual camera (signed)

1. Sign in to Xcode with the developer account: Xcode › Settings › Accounts.
2. Put the team's 10-character Team ID in `Signing.local.xcconfig` (ignored by git):
   ```bash
   echo 'DEVELOPMENT_TEAM = ABCDE12345' > Signing.local.xcconfig
   ```
3. Build and install into Applications:
   ```bash
   INSTALL=1 scripts/build-signed.sh
   ```
4. Open Matrix Eyes Cam from Applications and click **Install virtual camera**. macOS asks you to approve it in System Settings › General › Login Items & Extensions › Camera Extensions.
5. In Meet: Settings › Video › Camera › **Matrix Eyes Cam**.

When the app isn't running, the camera shows a card asking you to open it.

The project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`; `scripts/build-signed.sh` runs it for you.

## Developer checks

```bash
# one look on a still photo (prints GPU time per frame)
"Matrix Eyes Cam.app/Contents/MacOS/MatrixEyesCam" --render-test photo.png out.png bg=corridor subject=effect effect=hologram

# the real app, fed a still photo instead of the camera; saves frames + the controls panel, then quits
MATRIX_CAM_TEST_IMAGE=photo.png MATRIX_CAM_SNAPSHOTS=/tmp/snaps "Matrix Eyes Cam.app/Contents/MacOS/MatrixEyesCam"
```

`--render-test` keys: `bg` (room, blurred, tidy, space, matrix, aurora, synthwave, corridor, stairs, cathedral), `subject` (real, effect, material, fill, matrix), `effect` (edgeGlow, hologram, neon, pixelate, ghost), `material` (chrome, quartz, copper, bronze, doodle, print), `fill` (media, galaxy, fire, ocean, lava), `grade` (natural, noir, warm, cyberpunk), `bh=0/1`, `media=<image or video>`, `accent=r,g,b`, `t=<seconds>`.
